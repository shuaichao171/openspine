# OpenSpine — 骨架动画编辑器

基于 **libGDX 1.14.2 + 官方开源 Spine-libgdx 4.3.5 运行时** 的桌面 2D 骨骼动画编辑器（Java 17，LWJGL3）。

> 项目由 Spine 逆向工程工作区（`E:\Program Files\Spine Trial`）启发的重新实现。
> 从逆向获得的**技术认知**（骨架格式、骨骼层级/Pose 模型、运行时 API 结构）用于本项目设计；
> 代码全部基于**官方开源运行时**重新按 API 编写，未使用（也无法使用）混淆的 `s/*` 类作为源码。

## 功能

- **骨架渲染**：网格背景、骨骼线条与局部坐标轴、选中骨骼高亮 gizmo；可按项目 FPS 显示前后帧双色动画残影，循环动画在首尾正确回绕，并可选择同时显示残影骨骼；鼠标位于视口时可围绕光标平滑滚轮缩放，点击 Region/Mesh 的完整可见几何区域会按绘制顺序选中对应骨骼，悬停与选中的附件显示缩放无关的白色虚线轮廓，右侧附件选择也会同步轮廓；“界面”菜单可水平翻转视区、锁定滚轮缩放、在移动 Region 附件时按实际帧缓冲像素吸附，以及临时旁路全部约束检查未约束姿态，均不修改骨架作者数据；工具栏可聚焦选中骨骼或全览骨架与实际可见附件；“变形”工具可在当前动画时间直接拖动普通或加权 Mesh 顶点并自动写入 Deform 关键帧，`Shift` 点击可增删多选并整体变形；“权重”工具以多色热力点显示选中骨骼的逐顶点影响并支持笔刷增减
- **动画播放**：两行播放工作栏、动画列表、播放/暂停、按项目 FPS 逐帧前进/后退、帧号显示、全宽时间滑块、速度调节、复位；实时播放会按项目与事件音频路径触发声音，并应用事件音量、平衡和播放速度，暂停或切换文档/动画时立即停止，时间线拖动和逐帧跳转不会误播；切换动画会保持当前播放/暂停状态并立即显示首帧，暂停时切换皮肤也会保持当前槽时间线状态
- **骨骼编辑**：
  - 左侧骨骼层级树（点击选中 + 键盘筛选导航 + 右键菜单：新建子骨骼/删除/重命名/重置姿势/复制粘贴），从视口选择骨骼时自动展开并滚入对应节点
  - 视口中直接点击/拖拽骨骼，`Ctrl`/`Shift` 点击增减多选；工具模式：旋转 / 移动 / 缩放 / 倾斜。属性输入和拖动支持整组选中骨骼：移动使用共同世界位移，旋转/倾斜使用相对增量，缩放使用相对倍率；父子同时选中时，属性主目标提升到已选祖先，只直接变换选中子树根，子骨骼继承一次。自动打键覆盖实际修改的骨骼，手动“记录姿态”覆盖全部所选骨骼，每次整组操作可一次撤销
  - 右侧属性面板（X/Y/旋转/缩放/剪切，数值框 + 滑块实时编辑）；姿态模式自由摆姿势，可精确设置骨骼长度、预览 Spine 的五种父级变换继承模式并配置皮肤必需，再用“设为 Setup”将这些属性原子写入可导出的骨骼 Setup 数据；同时支持骨骼名称、颜色、图标/大小/旋转、可见性，以及编辑器侧的可选择和显示名称状态，后两项写入 Sidecar 并支持撤销/重做
  - 姿态操作支持最多 100 步撤销/重做；可将骨骼改到排列较后的父级，也可删除中间无引用的骨骼子树或槽，自动迁移动画、权重、约束、皮肤和关联网格索引。结构修改会先清理不安全的旧历史，本次操作可撤销/重做；循环父级和仍被附件、动画或约束引用的删除会被阻止并说明原因
- **附件 & 皮肤管理**：右侧标签页支持槽新增/重命名/受保护删除，管理 setup 浅色、可选双色染色暗色、混合模式、可见性、Region RGBA 染色与精确变换，以及皮肤空白新建/复制/重命名/删除/切换；可从 atlas 创建 Region 或 Mesh、把 Region 转换为 Mesh，并迁移已有 Sequence 轨道；也可选择跨皮肤/跨槽的独立源网格创建 Linked Mesh，或原位修改已有 Linked Mesh 的源网格、Deform 继承模式和图集区域而不破坏动画引用；也可创建并编辑 Bounding Box、Path、Point、Clipping；Region/Mesh 可配置 atlas 图片 Sequence 的基础路径、帧数、起始编号、补零位数和 Setup 索引，并逐帧校验图集资源；改变 Sequence 帧数时会无损迁移直接 Deform/Sequence 轨道、全部皮肤 owner、下游 Linked Mesh 源引用及独立/继承时间线归属；独立 Mesh 支持顶点、UV、三角形、外壳和边编辑，视口可直接插点拆面、三点建面、删点重排，几何编辑器可自动计算凸包或按索引顺序设置外壳，并同步重排普通/加权顶点、UV、拓扑、Linked Mesh 和 Deform；权重可按顶点以骨骼名称、局部坐标和比例结构化编辑，也可在视口直接绘制、自动归一化、按可调强度进行拓扑邻接平滑并保持 Setup 坐标；删除 Linked Mesh 或皮肤会回收不再需要的跨槽 Deform 激活引用，删除或替换附件与皮肤会保护 Deform、Sequence 与 Linked Mesh 源引用
- **属性撤销**：槽 setup 浅色/暗色、混合模式、可见性以及区域附件染色和变换均作为完整原子操作进入撤销历史；撤销/重做会同步重建运行时骨架。新建骨骼，以及动画的新建、复制、重命名和删除也可撤销；需要替换底层 BoneData 的骨骼重命名或改父级会先清理不再安全的旧历史，但本次操作本身仍可撤销
- **IK Setup 管理**：时间线工具栏可创建和编辑 Spine 4.3 IK 约束，配置一根或父子两根受约束骨骼、目标、混合、柔度、弯曲方向、压缩、拉伸、Y 缩放模式、皮肤必需及当前皮肤激活；修改后原子重建运行时骨架，无直接动画或皮肤引用的 IK 可从约束列表任意位置受保护删除，后续所有类型的约束轨道会自动无损重映射索引
- **Transform Setup 管理**：时间线工具栏可创建和编辑 Spine 4.3 Transform 约束，配置多个受约束骨骼、源骨骼、局部源/目标、叠加、限制、六种偏移与六个混合值、皮肤必需及当前皮肤激活；属性映射编辑器支持六种来源/目标属性、来源与目标偏移、最大值、缩放以及单来源多目标，新建约束可恢复六组同名默认映射
- **Path Setup 管理**：时间线工具栏可创建和编辑 Spine 4.3 Path 约束，配置有序受约束骨骼、目标槽、Position/Spacing/Rotate 三类模式、旋转偏移、位置、间距、旋转/X/Y 混合、皮肤必需及当前皮肤激活；更新保持统一约束索引并保护已有 Path 动画引用，目标槽依赖环会在修改前被拒绝
- **Physics Setup 管理**：时间线工具栏可创建和编辑 Spine 4.3 Physics 约束，配置目标骨骼、位置/旋转/缩放/剪切影响、限制、解算 FPS、惯性、强度、阻尼、质量、风力、重力、混合、七种全局作用域以及皮肤激活；更新保持统一约束索引，已有 Physics 动画引用不会失效。预览提供 Simulate 和 Deterministic 开关；开启 Deterministic 后，跳转、逐帧、拖动播放头和播放刷新都会从 0 按约束步长快进到目标时间，关闭时则使用实时 Physics 更新/重置语义
- **Slider Setup 管理**：时间线工具栏可创建和编辑 Spine 4.3 Slider 约束，选择目标动画并配置时间驱动或骨骼属性驱动、六种变换属性、来源范围、目标帧范围、Setup 时间与混合、叠加、循环、局部读取及皮肤激活；Frame 与 Mix 滑块和数值字段双向实时同步，骨骼属性驱动以来源最小/最大无损映射到动画起始/结束帧。更新保持统一约束索引，已有 Slider time/mix 动画引用不会失效
- **约束执行顺序**：五类约束编辑器显示其在 Spine 统一约束列表中的位置，并可跨类型上移或下移；重排会原子重映射全部约束动画轨道，保留帧值、曲线、全局 Physics 轨道和皮肤激活引用，并支持连续撤销/重做
- **时间线关键帧编辑**：骨骼旋转/平移/缩放/剪切及五种变换继承模式、IK/Transform/Path/Physics 约束、Slider 时间/混合、Mesh Deform、Region/Mesh Sequence、槽附件切换、RGBA 或拆分 RGB/透明度颜色、RGB2/RGBA2 双色轨道与全局事件轨道；左键选择关键帧、空白处左键拖动框选、`Ctrl`/`Shift` 追加或切换选择，拖动任一所选帧会移动整组，右键按住拖动可平移时间轴，`Delete` 删除所选帧；双击轨道空白可新增关键帧。Deform 可精确编辑整组顶点偏移，Sequence 可编辑播放模式、起始索引和帧间隔，Physics Reset、Sequence、继承、附件和事件使用离散关键帧，其余轨道支持线性、步进和已有贝塞尔曲线，
  关键帧时间/轴向数值/附件/Sequence 参数/浅色与暗色十六进制颜色精确编辑、复制粘贴与前后帧导航、线性/步进曲线切换；多选关键帧可作为跨轨道块复制，粘贴时保持相对时间、类型化数据和贝塞尔曲线，任一目标冲突会拒绝整块操作；动画支持新建/复制/重命名/删除，以及保留离散、步进、贝塞尔和显式保持帧的保守线性冗余帧清理；
  事件定义可新建、重命名、编辑默认载荷并受保护删除；单一定义保持一键加帧，多定义时可先选择定义并记住最近使用项；事件帧可编辑定义及整数/浮点/多行字符串/音量/平衡载荷；同一时间的多个事件保持稳定顺序，在轨道内错位显示并可直接逐个选择；
  “自动关键帧”位于“记录姿态”旁；开启后，视口拖动或骨骼属性数值编辑会在操作结束时自动记录本次修改的旋转、平移、缩放或倾斜通道，并遵循当前 XY Separate 设置，一次连续操作只产生一步撤销；同时支持一键记录选中骨骼的完整姿态、全部/选中骨骼/已有关键帧过滤和名称搜索，筛选隐藏的有效选择会在轨道重新显示后恢复；项目 FPS 可编辑、撤销和重做，点击及拖动按项目 FPS 吸附；
  Translate、Scale 与 Shear 支持 XY Separate 开关；Separate 会精确保留 runtime 通道曲线。异步轴 Combine 会保存两条原始轴轨道及曲线结构，组合轨道未再编辑时，后续 Separate 可精确恢复原始关键帧时间、逐通道曲线和轨道顺序；组合后若继续编辑，则按当前组合轨道拆分并只保证 runtime 采样等价。Graph 入口直接聚焦内嵌“曲线”页，在同一坐标系编辑多轨道和多通道；支持关键点和贝塞尔手柄编辑、平移缩放、全览或聚焦选择，同时保存每条轨道的视图范围与通道可见性；
  关键帧编辑支持撤销/重做，完整姿态和连续拖动分别合并为一步；删除关键帧或撤销/重做后会立即按当前播放头刷新视口；历史会跟踪保存点，回到已保存状态时自动清除未保存标记
- **可调工作区**：视口与时间线之间可拖动调整高度，长动画和多骨骼轨道可按当前任务扩展查看空间；滚动条与树展开控件保留稳定命中尺寸，长状态文本不会挤压主布局；时间线高度与缩放、轨道过滤、检查器页签、网格、骨骼、动画残影、事件音频、视区翻转、缩放锁定及像素吸附开关会在退出后保存并于下次启动恢复；“禁用全部约束”按骨架标签临时保留，不写入工程文件
- **项目设置**：项目级图片/音频路径、边界、参考缩放和 FPS 可统一编辑并撤销；动画预览支持默认混合时间及任意来源/目标动画对的单独混合时间，切换动画时立即应用，并通过 v11 Sidecar 随项目恢复
- **保存/另存为**：当前骨架+动画保存为 Spine 4.3 `.json`；Region、Mesh/Linked Mesh、Bounding Box、Path、Point、Clipping、Region/Mesh Sequence 及普通/加权顶点数据可无损保留，既有 Deform 顶点动画（线性/步进/贝塞尔）和 Region/Mesh Sequence 轨道也可完整往返；IK、Transform、Path、Physics、Slider Setup、皮肤激活引用和全部对应约束动画（含全局 Physics 及 Slider time/mix）以及事件定义与事件时间线同样完整往返。骨骼图标/颜色/可见性、皮肤与动画颜色、全局及局部绘制顺序也会保留。尚未支持的数据会在写文件前明确阻止保存；加载入口直接读取明确声明为 Spine 4.3 的 runtime 数据，明确声明的非 4.3 数据会在后台通过已安装并激活的官方 Spine CLI 转换。转换不会修改原文件，转换后的文档首次保存必须另存为；缺少版本或无法安全读取的文件仍会被拒绝，保存入口也保留版本与源文件覆盖的二次保护。保存和另存写入在可取消的后台任务中执行，取消会清理临时文件且不会覆盖已有目标；支持直接保存、覆盖确认和原子替换，记忆最近保存目录，窗口标题显示当前文档和未保存标记；保存、打开、拖放替换与关闭前会先提交当前工作区数值输入，避免遗漏刚键入的骨骼属性
- **项目诊断与恢复**：项目菜单可运行只读诊断，集中检查保存预检、图片与 Sequence、Linked Mesh、事件音频、输入/输出 Spine 版本以及 WebP/ffmpeg 可用性。编辑器每 60 秒把所有已打开骨架的 runtime 数据及完整 OpenSpine 编辑器状态写入用户数据目录中的原子自动保存快照，动画混合、XY Separate、曲线/时间线视图、选择与播放状态都会随崩溃恢复；保留最近 3 份，异常退出后下次启动可选择恢复、丢弃或稍后处理，正常退出会清理当前会话快照
- **PNG/JPEG 当前帧导出**：按当前应用姿态导出可见 Region/Mesh，自动裁切附件边界并支持百分比缩放与像素留白。PNG 可使用透明或编辑器深色背景，保留预乘 Alpha 或转换为普通直通 Alpha，并设置 0–9 压缩级别；JPEG 使用不透明深色背景并支持 0–100 质量设置。导出不包含网格、骨骼、残影、gizmo 等编辑器叠加层，在分配帧缓冲前校验 GPU 尺寸和像素数量，最终以原子替换方式写入目标文件
- **PNG/JPEG 动画序列导出**：将当前选中动画按 1–100 FPS 和指定帧范围导出为使用实际动画帧号的编号文件，例如 `walk_0002.png` 至 `walk_0012.png`；可关闭“包含末帧”，避免循环动画首尾相同姿态被重复导出。全部帧先扫描边界并使用统一画布，可在导出前预热动画 0–100 次，让 Physics 进入运动状态；PNG 支持透明背景、预乘/直通 Alpha 及 0–9 压缩级别，JPEG 支持质量设置。选择位置时只统计实际输出的整组已有文件并一次确认，所有帧编码完成后才批量提交；提交中断会删除新文件并恢复原序列，未经覆盖确认不会替换任何已有帧
- **GIF 动画导出**：将当前选中动画按指定帧率与帧范围导出为统一画布 GIF；可选择是否包含末帧，避免循环动画首尾重复。先扫描全部姿态取得稳定边界，再逐帧渲染，支持 1–100 FPS、缩放、留白、透明阈值、有限或无限循环，以及 0–100 次 Physics 预热。动画在独立骨架上从 Setup 姿态采样并推进 Physics 时钟，不会改变编辑器中的播放头或当前姿态；编码前限制单帧、总像素及帧数，文件通过临时文件原子替换
- **APNG 动画导出**：以完整 RGBA 无损帧将当前选中动画导出为 `.apng` 或 `.png`，沿用稳定画布和独立 Setup/Physics 采样；支持 1–100 FPS、可选包含末帧的帧范围、0–100 次 Physics 预热、缩放、留白、透明或深色背景、有限播放或无限循环，以及 0–9 zlib 压缩级别。编码器生成标准 `acTL/fcTL/IDAT/fdAT` 序列并使用累积帧延迟避免非整数帧率漂移，校验尺寸、总像素和帧数后通过临时文件原子替换
- **AVI 动画导出**：将当前选中动画导出为无需额外原生编解码器的 MJPEG AVI 1.0 视频，支持 1–100 FPS、可选包含末帧的帧范围、0–100 次 Physics 预热、缩放、留白和 0–100 JPEG 质量。每帧使用统一画布和独立 Setup/Physics 采样，生成标准 `avih/strh/strf/movi/idx1` 结构及完整关键帧索引；输出为不透明深色背景且不含音频，编码失败不会替换已有目标文件
- **WebM/MOV 动画导出**：通过 ffmpeg 把逐帧渲染结果编码为 VP9 WebM 或 ProRes MOV，支持帧率、帧范围、末帧开关、Physics 预热、缩放、留白、透明或自选不透明背景、最大分辨率及快速/平衡/高质量档位。选定范围内的 Spine 事件音频会按事件时间离线延迟并混合，保留音量和左右声像；WebM 使用 Opus，MOV 使用 AAC，音频在视频末尾截断。ffmpeg 失败会显示编码日志摘要，取消或失败不会替换已有目标
- **其他导出与长任务**：WebP 通过可选的 ImageIO WebP writer 导出当前帧；“扁平 PSD 当前帧”输出标准单画面 RGB+A 文件，不包含分层、骨骼或可编辑动画数据；HTML 内嵌固定版本 Spine Player 4.3.5 的脚本、样式和许可文本，以及 runtime 数据、atlas 和图片，可在断网时直接打开单个文件播放。支持外部图集及 loose 图片、中文资源名、组合皮肤和无动画的 Setup 项目；资源或播放器加载失败会明确显示原因。长动画先在 GL 线程每次测量或渲染一帧，再在后台编码 GIF/APNG/AVI/JPEG 序列/WebM/MOV；两个阶段均显示进度、支持取消，并通过暂存目录和原子提交避免留下半成品
- **文件加载与多文档**：可直接打开或导入 Spine `.spine` 编辑器工程，也可打开 `.json` / `.skel` 运行时骨架文件；项目菜单还可从 Runtime 文件向当前骨架导入单个动画，按名称严格映射骨骼、槽、约束、皮肤附件和事件定义，缺少目标或 Deform 拓扑不一致时整次拒绝。明确声明为 Spine 4.3 的 runtime 数据直接加载；明确声明的非 4.3 数据会在后台经过官方 Spine CLI 的“导入临时工程 → 导出 4.3 runtime”两阶段转换，原文件始终只读，转换后的文档首次保存必须另存为。版本检查发生在图集加载和 runtime 解析之前；缺失版本、损坏或无法安全读取二进制头，以及 CLI 缺失、无法启动或未激活时的旧版 runtime 文件都会被明确拒绝。一个 `.spine` 包含多个骨架时会一次导入全部骨架。左侧骨架选择器用于切换当前编辑对象，选择框右侧提供删除当前骨架按钮，旁边的“全部”按钮切换单骨架/全工程预览；每个骨架仍保留自己的撤销/重做栈，切换选择不再清空历史。已有持久化文档时，打开普通 runtime 文件会直接新增文档，不会要求先保存其他文档；尚未保存的新建文档仍会先确认，导入会替换当前工程的 `.spine` 时也会检查未保存修改。`.spine` 优先通过本机官方 Spine CLI 临时导出为 `json+pack`，CLI 缺失、无法启动或未激活时仅可安全回退到同目录匹配且已经是 4.3 的 `.json/.skel` runtime 导出，真实导出错误不会被旧文件掩盖，旧版 sibling runtime 也不能绕过官方转换。官方 `.spine` 始终只读；OpenSpine 使用格式 v11 的 `<source>.<ext>.openspine.json` 原子保存 `.spine`、`.json` 或 `.skel` 对应的动画/时间/皮肤、项目路径/边界/FPS/参考缩放、动画混合、骨骼/约束关系/槽/附件选择、Physics 预览、平移/缩放/剪切 XY Separate 偏好、可逆轴合并快照、Graph 轨道视图及 Graph 工作区状态，并用源文件名、大小、修改时间及 SHA-256 内容指纹拒绝过期状态，同时允许原样复制或 ZIP 解压后的时间戳变化。Sidecar 仅由 OpenSpine 读取，官方 Spine Editor 不会读取。CLI 转换在可取消的后台任务中执行，不阻塞编辑器渲染；最终 JSON/atlas/loose PNG 资源仍在渲染线程安全加载。JSON 和 `.skel` 使用图片附件时优先配对 `.atlas`；同目录存在多个候选图集时会先让用户选择，避免静默加载错误资源；没有 atlas 时可从 `skeleton.images` 指向的 PNG 目录动态创建图集；纯骨骼项目无需图集。预览与图像导出会遵循图集页的 `pma` 标记，无法由单一混合模式正确渲染的 PMA/直通 Alpha 混合页会在加载时明确拒绝；Windows 下所有打开、另存、工程重建、打包及图像/动画导出路径都使用绑定主窗口的系统 Explorer 风格文件窗口，覆盖确认也保持为主窗口的原生子窗口；其他平台回退到 Swing。文件窗口会记忆最近目录，启动文件与拖放加载也会同步最近路径
- **Spine 工程重建**：“导出项目 → 重建 Spine 工程”会把项目内全部骨架序列化为 Spine 4.3 runtime JSON，再通过已安装并激活的官方 Spine CLI 导入到一个新的可编辑 `.spine` 工程。多骨架按原项目名称逐个加入同一工程；全部导入成功后才原子替换目标，失败或取消不会破坏已有文件，也不会把 `.spine` 目标绑定为 OpenSpine 的普通保存路径。重建目标不能是作为导入源的原 `.spine` 文件。重建成功后会自动为新工程写入格式 v11 的 OpenSpine sidecar；sidecar 写入失败不会删除已成功生成的 `.spine`，并会单独提示。这是从当前 runtime 可表达数据重建新工程，不是对原 `.spine` 的无损回写：官方编辑器文件夹、布局/相机、Graph 选择状态、导出设置、撤销历史及未进入 runtime JSON 的元数据不会恢复，只有 atlas 而没有原始 loose 图片时也不能重造原图片目录
- **项目打包**：把项目内全部骨架的最新 JSON/SKEL、各自 atlas/loose PNG 和事件音频写入单个 ZIP；按骨架隔离资源目录，避免同名图片冲突，为新 runtime 文件生成匹配指纹的 Sidecar，并保存骨架顺序、活动骨架、全工程预览及 OpenSpine 编辑状态。从 `.spine` 导入的原文件单独归档且不修改。解压后打开根目录的 `openspine-project.json` 可恢复完整项目；不支持直接打开 ZIP。打包在可取消的后台任务中逐文件复制，取消不会替换已有压缩包；打包前校验资源，拒绝绝对、越界或大小写冲突的 ZIP 路径，并通过临时文件原子替换目标
- **皮肤组合与永久保存**：播放栏和附件面板的“组合…”可选择多个皮肤并调整覆盖顺序，后面的皮肤覆盖同槽同占位符附件；皮肤骨骼和约束取并集。“应用”只切换预览，最后一层是真实编辑皮肤；输入新名称并点“保存为新皮肤”，可生成独立的永久皮肤，包含默认皮肤回退附件，并复制对应的 Deform/Sequence 动画与曲线。Linked Mesh 展开为独立网格，之后编辑新皮肤不会影响源附件；该操作支持一次撤销/重做，保存工程或导出 JSON/SKEL 后保留。Sidecar 和 HTML 也保留预览组合，Slider 临时预览保持组合底层附件和真实编辑目标
- **OpenSpine 原生工程**：“项目 → 保存项目 / 项目另存为”将全部骨架、资源及编辑状态保存到 `.openspine-project.json` 工程，兼容解压项目包中的 `openspine-project.json`。打开工程后 Ctrl+S 保存整个工程；“管理骨架”可重命名及调整顺序，成员变化会触发未保存提示。新版本资源全部就绪后才原子替换工程清单，取消、失败或检测到骨架文件、状态、图集、图片或音频被外部修改时保留上一版工程；复制后的资源也须通过内容校验。完整内容校验在可取消的后台保存阶段完成，最后提交仅检查文件元数据并原子替换。普通“另存为”在工程中导出 Runtime 副本，不改变工程关联或保存点；重建 Spine 副本也不会清除原生工程的未保存标记。原生工程的自动旁存仅恢复视图，丢弃修改后不会复活未保存参数；成员修改的崩溃恢复保留整个工程并要求选择保存位置。两个内置示例也可完整保存、打包及带图重开
- **Setup 改父级补偿**：骨骼属性的父级对话框可选“保持 Setup 世界姿态”，求解新的本地变换并验证骨骼与顶点位置，支持继承模式、镜像、非均匀缩放和剪切，通过后可一次撤销/重做。此模式仅适用于无约束、相关骨骼及新旧祖先无骨骼动画和皮肤激活依赖、当前相关姿态已应用到 Setup 的情况；不能可靠保持姿态时拒绝修改。普通模式继续保留本地数值；尚未提供全动画补偿
- **移动坐标**：骨骼属性提供“父级 / 世界 / 本地”，同步切换数值和移动轴。“本地”的 ΔX/ΔY 沿主选骨骼自身的轴输入增量，包含该轴缩放，完成后归零；多选共用主选骨骼轴，各选中子树只移动一次。支持旋转、镜像、非均匀缩放和剪切。世界/本地轴移动和多骨骼移动会记录实际改变的本地 X/Y 通道；拖动或输入时按 Escape 取消，不留下关键帧。此开关只影响移动，世界值表示经过父级变换、尚未应用骨骼自身约束的编辑位置
- **自动网格与权重**：“附件皮肤 → 编辑网格”提供“图片轮廓”、“自动细分”和“自动权重”。图片轮廓默认生成单一无孔凹轮廓，也可选凸包；可调 Alpha 阈值、简化像素容差和顶点上限，支持图集旋转、裁边与翻转。凹轮廓保留透明凹口，孔洞、多岛和点接触轮廓会明确拒绝；仅适用于未加权、无锁定影响、无直接或 Linked Mesh 关联 Deform，且 UV 与顶点保持仿射关系的 Mesh。细分支持 1–4 级三角形重心插点；自动权重可选择参与骨骼、1–8 个最大影响及距离衰减，保留锁定影响和 Setup 位置。生成先进入几何草稿，通过校验后应用并支持撤销；已有 Deform 或 Linked Mesh 不允许的拓扑/影响结构变化仍会明确拒绝
- **内置示例**：程序化生成的人形骨架（3 个动画 idle/wave/walk），开箱即用
- **中文字体**：运行时字体图集覆盖 GB2312 常用简体中文和全部界面字符，常见中文骨骼、槽、皮肤及动画名称可直接显示；发布测试会阻止新增界面文案出现缺字

Deform/Sequence 附件轨道显示皮肤归属，搜索和悬停说明包含皮肤、槽、占位及实际附件；同名附件的选择状态按皮肤区分，旧状态只有在唯一匹配时才恢复，避免选中另一套皮肤的轨道。继承轨道仍归属于源附件，查看轨道不会切换当前预览皮肤。

皮肤新建、复制、重命名与受保护删除支持撤销/重做，并保留前后兼容的编辑历史；撤销皮肤改名后可以继续撤销此前的永久组合、姿态或动画编辑。已有的默认皮肤、引用与复制保护规则继续生效。

打开原生工程时，工程清单、图片和音频的完整资源检查在可取消的后台阶段执行；完成后在渲染线程加载候选纹理，再替换当前内容。取消、加载失败或准备期间发现文件/当前工程变化时保留原工程。纹理解码和上传仍在渲染线程进行，大量纹理的最终加载阶段仍可能短暂停顿。

加载操作会先在隔离的候选文档中完成骨架解析和动画状态初始化，全部成功后才替换当前内容；加载失败会保留原文档。

与本机 Spine Pro 4.3.23 的最新功能对照、验证范围及剩余差异见 [第十一轮审查记录](docs/spine-pro-review-2026-09-08-round11.md)。原生工程文件和同目录的 `.openspine-generations` 资源目录应一起保留；跨电脑传输建议使用“打包项目”生成 ZIP。当前保存会保留历史资源版本，尚未自动清理旧版本。

“项目 → 重新加载图片”（默认 `Ctrl+R`，可自定义）从当前图集或当前设置的图片目录刷新纹理，保留骨架姿态、播放位置、选择、未保存编辑和撤销/重做历史。所选图集缺失、图片损坏或任意皮肤的附件序列缺帧时整次拒绝，继续使用原图片并提示原因。刷新不重读骨架文件，也不新增作者撤销记录；已有历史可能引用的旧纹理保留到文档关闭。原生工程的外部修改检查仍然有效，直接修改其版本资源后可能需要另存为。

“界面”菜单和“设置 → 视口”新增隐藏视区选择（默认 `Shift+H`）与非活动皮肤骨骼参考（默认 `Shift+J`），可自定义快捷键并记忆开关。隐藏选择保留选中对象，隐藏轮廓、着色和 Gizmo，取消未完成手势并禁用隐形手柄/空白拖动；顶点和权重工具保留工作内容。非活动骨骼按 Setup 在活动祖先当前姿态下显示为只读参考，不激活皮肤或约束。视区顶部持续提示隐藏选择、参考骨骼、约束禁用、翻转、缩放锁定与像素吸附等状态，提示不拦截鼠标。

IK、Transform、Path、Physics、Slider 对话框提供“复制设置 / 粘贴设置”。会话内支持同类约束跨文档复制，按名称解析骨骼、槽和动画；保留目标名称与当前皮肤激活，关闭皮肤必需时清除激活。引用缺失或设置无效时整次拒绝；粘贴先填草稿，点击“应用”后才写入，并支持单步撤销/重做。Slider 保留秒值与映射，适应目标项目 FPS；不改时间字段时也不会产生帧换算精度漂移。创建约束后重命名/复制皮肤的连续撤销、重做会重新绑定当前约束，避免保留失效引用导致保存失败。

“项目像素网格”（默认 `Shift+P`）按每个世界坐标单位显示边界，叠加于图片之上，可独立于背景网格开关；间距达到 8 个实际屏幕像素时才显示，支持高 DPI、平移及视区翻转。此功能是坐标参考，不改变纹理过滤或导出内容，也未实现官方的像素不匹配高亮。背景网格采用有限数量的坐标索引，极大坐标下不会因浮点累加停止前进而卡住渲染。

PSD 图集默认保存在源 PSD 旁边（已有保存目录优先）；取消或完成导入只清理本次生成且未修改的临时 PNG，保留新图集和用户文件。关闭编辑器时也会清理尚未完成导入的提取结果。PSD 安装事务会检查所属骨架及挂载骨骼，拒绝把过期引用写进新骨架。

PSD 像素层按文件中的从底到顶顺序安装，避免背景盖住前景；图层继承所有上级组的隐藏状态，“忽略隐藏图层”也会排除隐藏组的子层。组仍按扁平列表导入，组不透明度、蒙版、特殊混合及剪贴尚未完整支持，会提示相关限制。

Graph 锁定时间后只修改数值、零偏移及“重设值”拖动会精确保留原有子帧时间；只有实际改变时间才应用吸附。独立 Graph 能同步撤销、重做及其他编辑入口替换的轨道，保持取景与选择，并取消过期的拖动预览；删除目标或切换骨架时关闭失效窗口。

摄影表关键帧与内嵌曲线把手在拖动期间遇到撤销、重做或外部文档变化时，会取消过期预览，松开鼠标不会覆盖恢复后的数据或清掉重做记录。

视区翻转或切换全部约束时，会先恢复尚未完成的骨骼、Mesh、Deform 和权重笔刷编辑；视区中的 Esc 也可取消这些手势，不新增关键帧或撤销记录。Region 沿旋转的父级/本地轴移动时，像素吸附沿该轴修正位移，保持被锁定的分量。骨骼父级坐标可在零缩放下直接编辑；可逆的极小或极大缩放支持世界移动。曲线通道编辑和关键帧复制粘贴会保留“两端相同、中间回弹”的贝塞尔数据；内嵌及独立 Graph 可正确显示、取景和拖动这类曲线的数值手柄。

## 构建 & 运行

```bash
build.bat          # javac 完整编译到独立临时目录，并发构建会排队，成功后替换 bin/
run.bat            # java 启动编辑器（首次自动 build）
run.bat --help     # 命令行参数和 MCP 工具说明
trace.bat --help   # Physics/Slider 官方 golden trace 捕获与比较
publish.bat        # 编译、测试并生成 publish/OpenSpine 与 win64 ZIP
```

需要 **JDK 17+**。`--add-opens java.base/java.lang=ALL-UNNAMED` 已包含在 `run.bat`。

WebM/MOV 导出需要 ffmpeg。可把 `ffmpeg` 加入 PATH、设置 `OPENSPINE_FFMPEG`，或在“设置 → 导出”中填写并验证可执行文件路径；未检测到时对应入口自动禁用。WebP 导出需要 JVM 中已注册 ImageIO WebP writer，缺失时 WebP 入口同样禁用。PNG、JPEG、GIF、APNG、AVI、扁平 PSD 当前帧和 HTML 动画播放页不依赖这两个外部编码组件。

打开或重建 `.spine` 工程还需要本机安装并激活官方 Spine Editor。OpenSpine 会自动查找 PATH 和常见安装目录中的
`Spine.com`；也可通过环境变量 `OPENSPINE_SPINE_CLI` 指定完整路径，或在 JVM 启动参数中设置
`-Dopenspine.spine.cli="C:\Program Files\Spine\Spine.com"`。独立归档的研究资料不会作为工程解析器加载。
一个 `.spine` 中包含多个骨架时，OpenSpine 会导入 CLI 导出的全部骨架并共享其临时图片资源。

Physics/Slider 的逐帧兼容性使用“官方侧采样 JSON → OpenSpine actual JSON”对照，避免用
OpenSpine 自己生成 expected。官方 golden 必须声明 `producer: "Spine Editor"`、官方版本、
Spine 数据版本和输入源 SHA-256；命令会拒绝来源不明或由 OpenSpine 生成的 golden。`trace.bat capture` 可生成 actual 并同时比较 `--golden`，
`trace.bat compare` 可重复比较两份已有 trace；首个差异会输出帧、时间、通道、期望值、实际值和容差。
格式、场景矩阵和命令示例见 [docs/runtime-golden-trace.md](docs/runtime-golden-trace.md)。

> 若只想跑逻辑冒烟测试（不依赖 GL/窗口）：
> `java -cp "bin;lib\*" com.openspine.io.SmokeTest`

JSON 皮肤导出另有跨运行时检查：构建后运行 `node scripts/test-json-export.cjs`，使用内置官方
Spine 4.3.5 TypeScript 读取器检查皮肤、附件及关联动画，无需浏览器或 npm 依赖。Java 发布测试也会自动
运行 `SkinJsonExportTest` 的容器类型断言，避免 libGDX 同时接受对象和数组而漏检。
修复范围和复现说明见 [JSON skins 导出兼容性修复](docs/json-skins-export-fix.md)。

发布流程需要带 `jpackage` 的 **JDK 17+**，会依次运行加载播放、文件往返、安全导出、动画编辑、撤销历史和结构删除回归测试。
默认发布版本为 `0.2.91`，产物位于 `publish/OpenSpine` 和 `publish/OpenSpine-0.2.91-win64.zip`。

## MCP 服务

构建脚本会生成 `openspine-build.properties`，记录 UTC 构建时间、源码/资源/依赖/构建脚本的 SHA-256、
Git 提交和工作区是否含未提交改动。`run.bat --version` 与发布版 `OpenSpineMCP.exe --version` 显示这些信息；
MCP 握手的 `serverInfo.version` 带源码指纹后缀，完整信息位于 `serverInfo.build`。
比较不同构建时请核对指纹，不要只比较基础版本号 `0.2.91`。手工覆盖 class 文件后应重新运行构建脚本。

OpenSpine 内置换行分隔 JSON-RPC 的 **stdio MCP 服务**。它作为无窗口子进程运行，使用官方 Spine 4.3 runtime
解析项目；文件概览、读取、校验和写入不需要 OpenGL、atlas 或纹理。渲染预览使用独立的隐藏 OpenGL 进程，
截图通过显式启用的编辑器取得自身画面。服务只允许访问 `--root` 下的项目与渲染素材，
不会直接修改已打开编辑器的内存文档，外部写入后需在编辑器中重新打开项目。MCP 模式要求显式传入
`--root`，避免客户端启动目录不同而意外扩大文件访问范围。

```bat
run.bat --mcp --root "D:\SpineProjects"
```

发布包还包含控制台启动器 `OpenSpineMCP.exe`，它已默认附加 `--mcp`。例如 Codex 的
`~/.codex/config.toml` 可配置为：

```toml
[mcp_servers.openspine]
command = "C:\\Tools\\OpenSpine\\OpenSpineMCP.exe"
args = ["--root", "D:\\SpineProjects"]
```

Claude Desktop 等使用 JSON 配置的客户端可使用同一启动器：

```json
{
  "mcpServers": {
    "openspine": {
      "command": "C:\\Tools\\OpenSpine\\OpenSpineMCP.exe",
      "args": ["--root", "D:\\SpineProjects"]
    }
  }
}
```

源码构建环境若尚未生成发布包，可把客户端命令设为 `cmd.exe`，参数设为
`["/d", "/c", "E:\\Program Files\\OpenSpine\\run.bat", "--mcp", "--root", "D:\\SpineProjects"]`。

| MCP 工具 | 用途 |
| --- | --- |
| `openspine_list_projects` | 使用 Spine runtime 验证并分页发现根目录下的 `.json` / `.skel` 项目，可限制子目录深度 |
| `openspine_inspect_project` | 无纹理解析 `.json` / `.skel`，返回骨骼、槽、皮肤、约束、动画、时长、边界及 SHA-256 |
| `openspine_read_project` | 读取不超过 512 KiB 的完整 `.json`、结构摘要和后续安全写入所需的 SHA-256 |
| `openspine_read_project_chunk` | 按 Unicode 字符范围分块读取较大的 `.json`，同时返回完整文件 SHA-256 和结构摘要 |
| `openspine_validate_project` | 校验磁盘项目或尚未写入的完整 JSON，不修改文件 |
| `openspine_write_project` | 通过 runtime 校验后原子写入 `.json`，可创建 `.bak` 备份 |
| `openspine_render_preview` | 将已保存 `.json` / `.skel` 按皮肤、动画与秒数渲染为 PNG，可返回最多 8 个统一取景的动画采样帧 |
| `openspine_capture_screenshot` | 截取已显式启用截图的 OpenSpine 编辑器客户区，包含当前可见的未保存内容，不抓取桌面或其他应用 |

### MCP 校验范围

`openspine_validate_project` 保留兼容字段 `valid`，同时返回 `structure_valid`、`textures_checked`、
`render_checked` 和 `warnings`。结构校验成功时 `valid` 与 `structure_valid` 为 `true`，后两项为 `false`；
缺少贴图的项目仍可通过结构检查，不能据此认为它已经通过视觉验收。

JSON 在交给 runtime 之前会检查索引的整数类型和范围，防止小数或超出 16 位的值被截断后漏检；
解析后继续检查三角形/边索引、UV 与顶点数量、hull、加权骨骼索引、完整影响数据以及几何数值的有限性。
相同检查用于读取、发现、写入和预览入口，非法网格会在渲染之前拒绝。权重和不接近 1 时返回警告，
不自动归一化或改写原数据；零权重和、负权重及重复骨骼影响会被拒绝。

空动画时间线会在 runtime 解析前被拒绝，并返回路径，例如 `animations.idle.events`；
无事件时应省略 `events` 字段，`"idle": {}` 仍然有效。关键帧内部合法的 `vertices: []`、
`offsets: []` 不按空时间线处理。运行时异常会保留动画名称及底层原因，异常链最多 8 层、总长度最多 4096 字符。

渲染预览成功时会返回 `textures_checked: true`、`render_checked: true` 和 `render_scope: "requested_frames"`。
这只表示指定采样帧成功渲染，不表示已扫描全部动画的网格翻折、循环接缝或美术质量。

### MCP 图片与预览

两项图像工具均直接返回 MCP `content` 中的 `type: "image"`、`mimeType: "image/png"` 和 Base64 `data`，
而非只返回本地图片路径。尺寸、动画时间等描述放在 `structuredContent`；多帧预览的 `frames[].image_index`
对应从零开始的图像内容块序号。客户端须支持 MCP 图像内容，模型须具备视觉能力，才能直接理解返回的图片。

渲染预览不需要打开编辑器，也不会修改项目。例如 `tools/call` 的参数：

```json
{
  "name": "openspine_render_preview",
  "arguments": {
    "path": "hero.json",
    "animation": "walk",
    "time": 0,
    "end_time": 1,
    "frame_count": 4,
    "width": 512,
    "height": 512,
    "transparent": true
  }
}
```

省略 `animation` 时返回 Setup 姿态；单帧用 `time` 指定秒数。可传 `skin`、同目录 `atlas` 文件名、
`padding` 与 `background: "#RRGGBB"`。需要可用的 OpenGL 驱动，以及根目录内的 atlas 页面或
`skeleton.images` loose 图片；素材引用越界、丢失、图集选择不明确或没有可绘制附件时返回明确错误。
每帧宽高为 64–2048 像素，默认 512；最多 8 帧，所有帧合计不超过 4,194,304 像素和 16 MiB PNG 数据。
采样时间为 0–60 秒且不能超过动画时长，多帧默认结束时间为动画时长与 60 秒的较小值。渲染 45 秒超时，
取消调用会终止本次隐藏渲染进程并清理临时文件。发布包中的 `OpenSpinePreview.exe` 是渲染助手，必须保留。

截图默认关闭。需要截图时，以和 MCP `--root` **相同的目录**启动编辑器：

```bat
OpenSpine.exe --mcp-capture-root "D:\SpineProjects" "D:\SpineProjects\hero.json"
```

随后调用：

```json
{"name":"openspine_capture_screenshot","arguments":{"path":"hero.json","max_width":1280,"max_height":960}}
```

目标项目必须在编辑器中处于活动状态，所有打开的文档也必须有授权目录内的已保存文件路径。
多个编辑器同时打开此项目时须传 `editor_pid`；截图按原比例缩小，不放大。截图不切换焦点、不点击界面，
不包含系统桌面、其他应用、操作系统标题栏或原生文件对话框。编辑器最小化或停止绘制时可能在 10 秒后超时。
截图可能暴露可见的未保存内容、最近路径等界面文字，请只向可信客户端启用。关闭编辑器会注销本次截图服务。

更新已有文件时，应先调用 `openspine_read_project`，再把返回的哈希作为 `expected_sha256` 传给
`openspine_write_project`。文件在两次调用之间发生变化时，写入会被拒绝；只有明确传入 `overwrite=true`
才会跳过“先读后写”要求。单个项目 JSON 上限为 16 MiB；完整内联读取上限为 512 KiB，较大文件应使用
`openspine_read_project_chunk`；单条 JSON-RPC 消息上限为 34 MiB，输入必须是有效 UTF-8。工具调用通过
有界队列串行执行，并支持 stdio `notifications/cancelled` 取消尚未完成的请求。项目发现会排除普通配置 JSON
和损坏项目；单次发现最多验证 128 MiB 候选文件，超过时应缩小目录或深度。

服务同时支持最新 MCP `2026-07-28` 的 `server/discover` 与逐请求元数据，以及
`2024-11-05`、`2025-03-26`、`2025-06-18`、`2025-11-25` 的旧版 `initialize` 握手。

## 使用

1. 启动后自动加载内置示例（小人），默认播放 `walk` 动画。
2. **动画**：底部下拉选择 idle/wave/walk；使用播放/暂停、上一帧/下一帧、复位和循环按钮控制预览。逐帧操作会自动暂停并按项目 FPS 精确跳转，也可直接输入帧号、拖动时间线或调节速度；帧号输入用 `Enter` 提交、`Esc` 恢复，未提交就离开输入框时也会恢复实际帧，并可准确到达不对齐整帧的动画末端。
3. **选骨骼**：左侧树点击，或在视口中单击骨骼线条、Region 图片或 Mesh 的三角形区域；重叠附件优先选择绘制顺序最上层的骨骼。拖动左侧树与视口、视口与右侧检查器之间的分隔线可调整两侧栏宽度，布局会在下次启动时恢复。“界面”菜单可水平翻转视区或锁定滚轮缩放；翻转后拾取、拖拽、平移和光标锚点缩放仍使用所见坐标，骨骼名称不会镜像。
4. **编辑**：顶栏切换 旋转/移动/缩放/倾斜 工具，在视口拖拽选中骨骼；倾斜工具的红色 X 与绿色 Y 手柄分别修改对应角度通道。也可用右侧滑块、数值框精确修改。“像素吸附”只在移动 Region 附件时按屏幕实际像素对齐附件原点；“禁用全部约束”只旁路当前骨架的预览求值，不改变约束 Setup、动画混合值或导出数据。数值框只接受有限数值，输入无效时会明确提示并保留焦点以便修正，`Esc` 可取消本次输入。姿态模式下可精确调整导出长度，选择全部、仅平移、无旋转或反射、无缩放、无缩放或反射五种父级变换继承模式，并设置骨骼是否为皮肤必需；继承模式会立即更新预览且可撤销。当前局部姿态、长度、继承模式或皮肤必需与骨骼 Setup 不同时，“设为 Setup”按钮会启用。属性面板还可修改骨骼名称、颜色、图标/大小/旋转和可见性；“选择”和“名称”是编辑器专用状态，写入 Sidecar 并支持撤销/重做。全部属性作为一次原子操作写入，可撤销/重做，外观不会跳变，并会随 JSON 保存。
5. **骨骼管理**：左侧树**右键**选中骨骼 → 新建子骨骼 / 删除 / 重命名 / 重置姿势 / 复制粘贴属性或整棵骨骼子树。子树粘贴会追加到目标骨骼下，自动解决全部名称冲突，并保留 setup 姿势、长度和显示元数据；槽、附件、约束与动画不会随骨骼子树复制。树获得焦点后可用上下键选择、左右键折叠或进入层级、`F2` 重命名、`Delete` 安全删除、`Esc` 清除筛选；筛选框按向下键可直接进入树。筛选、撤销和结构刷新会保留原有折叠状态，从视口选中隐藏在折叠分支中的骨骼时会自动展开其父路径。菜单支持上下键选择、`Enter` 执行和 `Esc` 关闭，点击菜单外部只会关闭菜单，不会误触下层控件。骨骼和动画重命名窗口会全选当前名称，支持 `Enter` 提交和 `Esc` 取消；名称未变化时不会清空撤销历史。
6. **附件皮肤**：切换右侧“附件皮肤”标签页，可为选中骨骼新增或重命名槽；无附件、动画和约束引用的槽可安全删除。面板可从 atlas 创建/替换 Region 或 Mesh、把 Region 转为 Mesh；选择 `Linked Mesh` 后可从“皮肤 · 槽 · 占位名”列表选择独立源网格、另选图集区域，并切换“继承 Deform”或“独立 Deform”。更换独立 Linked Mesh 的源网格时会迁移既有 Deform；切换到继承模式前必须先删除该 Linked Mesh 的直属 Deform/Sequence 轨道，避免保存永不生效的数据。通过“编辑网格”可校验和修改独立 Mesh 的顶点/权重、UV、三角形、外壳与边；也可直接创建 Bounding Box、Path、Point、Clipping，并在类型化窗口中编辑普通/加权顶点、Path 曲线长度和闭合模式、Point 位置与旋转、Clipping 结束槽及凸/反向选项。图片与标准附件会在视口显示并可点击选择，鼠标悬停、视口点击或右侧附件选择都会显示对应的白色虚线轮廓。Mesh 工具可直接拖动无权重顶点，`Shift` 点击可增删多选并整体移动；`Ctrl` 点击三角形内部会按重心坐标插入普通或加权顶点并自动拆成三个面，选择恰好三个顶点后按 `Enter` 建面，按 `Delete` 删除选中顶点及关联面并重排 UV、权重、边和索引。插入或删除顶点会同步迁移源 Mesh 与独立 Linked Mesh 的普通/加权 Deform 帧；移动未加权 Mesh 或标准顶点附件的 Setup 顶点时，也会重基准内部帧以保持导出的 Deform 偏移不变。选择目标骨骼后切换“权重”工具，可在 Mesh 上拖动增加该骨骼权重，按住 `Shift` 拖动则降低；颜色由冷到暖表示 0 到 1，新增影响会使用该骨骼的 Setup 局部坐标并自动归一化。已有 Deform 时不能增加、删除或替换单个顶点的影响骨骼，但可重排同一骨骼集合，相关普通 Mesh、独立 Linked Mesh 和标准附件 Deform 对会自动跟随骨骼重排。“编辑网格”中的平滑强度滑杆和“平滑权重”可按三角形邻接柔化权重过渡，并保留现有影响结构以兼容 Deform。也可编辑槽 setup 颜色、混合模式、可见性、Region 变换以及管理皮肤。Apply 和重命名按钮仅在规范化后的草稿真正变化时启用，校验失败时保留焦点，`Esc` 恢复当前模型值。
   时间线工具栏的“IK 约束”、“Transform”、“Path”、“Physics”和“Slider”可新建或编辑对应 Setup，并配置当前皮肤激活；约束选择器右侧显示统一执行位置，`^`/`v` 可跨类型调整顺序。删除前必须先清除对应的皮肤激活和动画轨道引用。满足条件后可直接删除列表中间的约束，重排或删除时所有类型的约束轨道索引、帧值与曲线会自动保持一致。
   左侧约束分组会展开显示全部受约束骨骼以及 IK 目标、Transform 来源、Path 目标槽、Physics 模拟骨骼和 Slider 属性来源/目标动画；选中约束时视口同时高亮全部关联骨骼，而不是只选择一个代表骨骼。
7. **动画制作**：中间时间线面板选动画，可设置项目 FPS，并按全部轨道、选中骨骼或已有关键帧过滤及搜索轨道；搜索框用 `Enter`/`↓` 返回画布，`Esc` 先清空再退出。FPS 与关键帧时间、数值、颜色字段成功提交后自动聚焦画布，校验失败保留焦点，`Esc` 恢复模型值。“自动关键帧”开关与“记录姿态”位于同一工具栏；开启后，移动、旋转、缩放、倾斜骨骼或提交右侧骨骼数值，会在当前吸附帧仅写入本次编辑通道，组合 XY 轨道写入两个当前轴值，Separate 模式只写入被编辑轴，自由双轴变换写入两个独立轴，一次拖动或数值提交可整体撤销。“记录姿态”或 `K` 仍可在当前播放头一次写入选中骨骼的旋转、平移、缩放和剪切。左键点击选择关键帧，在空白区域拖动可跨轨道框选，`Ctrl`/`Shift` 点击或框选用于追加和切换选择；拖动任一所选帧会整体移动，`Delete` 或“删除帧”会一次删除全部所选帧，右键按住拖动可水平和垂直平移时间轴。双击骨骼数值/继承、IK/Transform 约束、槽附件、槽颜色、双色、全局绘制顺序或事件轨道的空白处可添加单个关键帧；IK 帧会采样当前运行时约束姿态，可精确编辑混合、柔度、弯曲方向、压缩和拉伸，并仅对混合与柔度应用曲线；Transform 帧会采样六个运行时混合值，并对全部六通道保留独立贝塞尔曲线；“选中骨骼”过滤会保留源、目标或受约束骨骼相关的约束轨道。绘制顺序帧会采样当前运行时顺序，并可在弹窗中上移、下移槽或恢复 Setup 顺序。继承轨道用下拉框编辑五种离散模式，不提供曲线按钮，普通 RGBA 颜色使用 `#RRGGBBAA`，拆分 RGB 使用 `#RRGGBB` 并以独立数值编辑透明度，双色帧并排编辑浅色 `#RRGGBB[AA]` 与暗色 `#RRGGBB`。“事件定义”用于新建、重命名、修改或安全删除全局定义；只有一个事件定义时双击轨道空白直接加帧，存在多个定义时会在吸附后的时间打开选择窗口，并默认最近选中或使用的定义，`Enter` 添加、`Esc` 取消。事件检查器可切换定义并编辑时间，“载荷…”可编辑整数、浮点、多行字符串及音频音量/平衡，多行框用 `Ctrl+Enter` 提交。同一时刻的事件标记会在轨道行内上下错开，点击、组拖动和批量删除均按二维最近标记精确操作，检查器同时显示组内序号。选择、拖动关键帧或点击标尺会暂停并精确同步播放头；数值检查器按轨道显示轴向、角度或倍率。选中非末帧后可切换线性、步进，或点击“贝塞尔…”打开带拖拽手柄、控制点字段和缓动预设的曲线编辑器；曲线编辑是一个可撤销操作，并统一映射到轨道的全部连续数值通道。单帧复制会保留完整的逐通道曲线、IK 离散选项、继承模式、绘制顺序或事件载荷，贝塞尔轨道在插入、移动、编辑、粘贴或删除时会保留并重新映射相关采样。复制整段动画同样会保留全部曲线、离散轨道和事件数据，也可拖动更宽的上下分隔线调整时间线高度；时间线高度、缩放和轨道过滤会在下次启动恢复。
 Path 位置、间距与三通道混合轨道、局部/全局 Physics 数值与 Reset 轨道，以及 Slider 时间/混合轨道，均支持加帧、检查器编辑、拖动、复制粘贴、删除和撤销/重做；除 Reset 外的连续轨道支持曲线。
 内嵌“曲线”页与摄影表选择同步：Ctrl/Shift 多选或框选多个连续轨道后，会在同一坐标系叠加显示全部通道曲线，并支持跨轨道点选、框选与批量移动；当前主轨道仍负责贝塞尔控制柄和数值检查器编辑。
内嵌曲线编辑支持逐通道显隐与独立曲线、`Ctrl`/`Shift` 多选、框选、批量移动、重定时、重设值、帧吸附和自动取景；平移、缩放和剪切轨道均可在组合 XY 与 Separate X/Y 间转换。不同内部关键帧时间会按时间并集重建组合帧；若组合轨道未继续编辑，Separate 会从持久化快照精确恢复原 X/Y 帧、曲线和轨道顺序，组合后再编辑则按当前组合轨道拆分并保证 runtime 采样等价。旧 Sidecar 中的独立 Graph 窗口状态会自动迁移到内嵌曲线页。
关键帧“应用”仅在规范化后的时间、数值、颜色、附件/事件选择或线性/步进曲线确有变化时启用；等价的科学计数法、颜色大小写和 RGB/RGBA 写法不会产生虚假的待提交状态，无效但已变化的草稿仍可提交并获得精确校验提示。

8. **保存与重建**：顶栏“保存”会按关联路径直接写入 JSON 或 `.skel`；“另存为”可选择 Spine JSON 或二进制格式。OpenSpine 固定输出 Spine 4.3.0，并直接读取明确声明为 4.3.x 的 runtime 数据；明确声明的非 4.3 JSON / `.skel` 会在后台通过已安装并激活的官方 Spine CLI 转换为 4.3 后打开。转换不修改输入文件，转换后的文档没有普通保存关联，首次保存会自动进入另存为；缺少版本、二进制头损坏或 CLI 不可用时仍会在解析前拒绝加载。4.3.x 数据可按关联路径保存，保存层仍会阻止任何不兼容数据覆盖其输入源。从 `.spine` 导入的工程和内置示例首次保存也会自动进入另存为，不会覆盖原 `.spine`。需要新的官方编辑器工程时，使用“导出项目 → 重建 Spine 工程 (.spine)”并另选目标；该操作通过官方 CLI 从当前 runtime 数据创建新工程，不会改变普通保存路径，并在成功后为新工程生成 OpenSpine v11 sidecar。Sidecar 中的选择/视图、动画混合和可逆轴合并状态只在 OpenSpine 内恢复；官方编辑器专有布局、文件夹和未导出工程元数据不能从 runtime JSON 推导，因此不等同于保真回写原 `.spine`。
9. **打开文件**：工具栏“打开”、项目菜单“导入项目”，或把 `.spine` / `.json` / `.skel` 拖入窗口；也可把文件路径作为 `run.bat` 的启动参数。`.json` / `.skel` 包含 Region/Mesh 图片附件时可使用同目录匹配的 `.atlas`；没有 atlas 时两种格式都可通过 `skeleton.images` 指向 loose PNG 目录。
10. **诊断与恢复**：项目菜单“项目诊断”可在保存或发布前检查资源与兼容性。若上次运行异常结束，启动时会显示自动保存恢复窗口；恢复结果作为未保存文档打开，应检查后另行保存到正式项目文件。

关闭窗口、导入会替换当前工程的 `.spine`、新建工程或切换到内置示例时，如果存在未保存的修改，编辑器会提供“保存 / 不保存 / 取消”三种选择；已有持久化文档时，普通 `.json` / `.skel` 会作为新标签打开，未保存的新建文档不会被静默替换。选择保存但操作失败或取消另存为时，不会继续丢弃当前文档。骨骼、槽、附件、皮肤和动画删除均会二次确认，确认窗口支持 `Enter` 确认和 `Esc` 取消。模态窗口和右键菜单打开时，全局快捷键会暂停，避免操作穿透到后方编辑器；关闭后会恢复此前有效的键盘焦点，时间线、树和父级窗口可继续直接使用快捷键。

姿态模式中的自由摆姿势是临时预览，可撤销/重做；把当前姿态添加为时间线关键帧后才会写入可导出的动画数据。

常用快捷键：`Ctrl+O` 打开、`Ctrl+S` 保存、`Ctrl+Shift+S` 另存为、`Ctrl+Z` 撤销、`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做、`Space` 播放/暂停、`,`/`.` 前进/后退一帧；
`Q/V/C/X/Z/T/Y/G` 切换选择/移动/旋转/缩放/倾斜/Setup 顶点/Deform 变形/权重，`B` 切换 Pose/Animate，`K` 记录选中骨骼姿态，`F` 聚焦选中，`Home` 显示全部，`Shift+G`、`Shift+B`、`H` 切换网格/骨骼/动画残影，`Shift+F` 翻转视区，`Shift+L` 锁定缩放，`Shift+I` 切换像素吸附，`Shift+C` 启用/禁用全部约束；
时间线获得焦点后可用 `←/→` 切换相邻帧、`Delete` 删除帧、`Ctrl+C/Ctrl+V` 复制粘贴帧。

文本输入框获得焦点时，撤销/重做快捷键只修改输入内容，不会意外撤销骨架或时间线数据；点击输入框外的时间线、树、滑块或工具栏后会结束文本焦点，工作区快捷键可立即继续使用。

## 已知限制

- 编辑器不依赖任何破解/逆向代码，是基于官方开源运行时的独立实现；Mesh/基础拓扑/外壳计算与重排/结构化权重、权重笔刷与拓扑邻接平滑/Deform、Region/Mesh Sequence Setup 与轨道、全部四类约束 Setup 与基础关键帧，以及 Bounding Box、Path、Point、Clipping 的创建和属性编辑均已可用。跨槽且继承 Deform 的 Linked Mesh 共用源 Mesh 的 Deform 轨道，视口编辑会自动归入源槽，避免生成 Spine JSON 无法定位的重复轨道。
- 当前 JSON 与 `.skel` 导出支持骨骼、槽、全部标准附件类型（含普通/加权 Mesh 与 Linked Mesh）、附件 Sequence、Deform 与 Sequence 动画轨道、IK/Transform/Path/Physics/Slider Setup 与皮肤激活引用及全部对应动画（含全局 Physics 和 Slider time/mix）、可视化编辑的事件定义与事件时间线、全局/局部绘制顺序、槽附件切换、RGBA 或拆分 RGB/透明度颜色、RGB2/RGBA2 双色、骨骼变换继承离散轨道，以及旋转、平移、缩放、剪切轨道（线性/步进/贝塞尔）；骨骼、皮肤和动画的编辑器颜色及骨骼图标元数据也可往返。二进制写出会使用同版本官方 `SkeletonBinary` 回读测试；格式无法无损表示的数据会明确阻止导出，避免静默丢失。
- 使用 Region/Mesh 图片附件时（内置示例除外），需用户提供 Spine 导出文件与图片资源；JSON 和 `.skel` 均可使用 `.atlas + 图片`，也可使用 `skeleton.images` 指向的 loose PNG；纯骨骼项目只需骨架数据文件。

# Spine Pro 对照审查：第二轮

审查开始：2026-09-07；完成：2026-09-08（北京时间）。参考版本：本机 `spine_jar/Spine Pro/Pro_4.3.23.jar`；OpenSpine 使用 Spine-libgdx 4.3.5。

本轮根据参考包的界面语言、快捷键及播放器模板确认功能入口，再审查 OpenSpine 的实现、数据往返和实际渲染。没有启动参考编辑器，也没有读取或复用其闭源实现。参考资源证明功能存在，不能证明交互细节或数值行为完全一致。

## 本轮完成

| 功能或问题 | 对比及发现 | 本轮修改 |
| --- | --- | --- |
| 多皮肤组合 | Pro 资源含合并皮肤、固定皮肤、皮肤骨骼与约束；原软件只能切换单皮肤 | 播放栏、附件面板增加有序组合；后层覆盖同槽同占位符，激活骨骼与约束取并集；最后一层为真实编辑目标；不污染导出的原始皮肤数据 |
| 组合状态往返 | 组合只在视口存在会导致重开、导出与预览不同 | Sidecar 保存层顺序、完整骨骼多选；结构重建和皮肤改名保留组合；HTML 使用公开 4.3 Player 的多皮肤配置 |
| Slider 临时预览 | 临时皮肤原先只包含顶层，底层附件消失；提交时可能误选 default | 临时预览保留整个组合，恢复后再解析编辑目标；预览期间的状态保存也使用真实皮肤层 |
| 移动坐标 | Pro 资源区分 Local、Parent、World；原软件移动轴与属性坐标不一致 | 增加父级、世界移动模式，属性 X/Y 与移动轴同步；转换包含父级旋转、缩放、剪切和根骨骼缩放 |
| 世界轴自动打键 | 世界 X 位移可能同时改变本地 X/Y，原按轴只记录一个通道，跳帧后姿态丢失 | 世界轴及多骨骼平移记录所需的两个本地通道；回归检查打键后重新采样的位置 |
| 连续拖动取消 | 取消或切换选择后可能误提交旧对象变换 | Escape 回滚本次骨骼拖动；失效选择不再提交旧骨骼关键帧 |
| 自动网格 | Pro 资源有 Generate、Trace、Concavity；原新增的自动轮廓只生成凸包 | 默认单一无孔凹轮廓；Alpha、像素简化容差、顶点上限；保持拓扑简化与约束 Delaunay 三角化；保留凸包选项 |
| 网格数据保护 | 重建轮廓即使顶点数不变，也会改变 Deform 顶点对应 | 拒绝加权、锁定影响、直接或关联 Linked Mesh Deform 的轮廓重建；孔洞、多岛、点接触、超限图像在应用前拒绝 |
| 槽重排 | 调用方各自迁移时间线，容易重复或漏迁移 | 编辑器内部统一迁移附件、时间线、绘制顺序、剪裁等引用，失败回滚；UI 记录一次撤销并显示错误 |
| 结构撤销 | 快照保留可变 SkinEntry，后续附件替换能污染历史；Linked Mesh 可能丢失共享权重 | 使用不可变附件位置记录，保留源网格与关联网格的共享权重关系；覆盖重排、撤销、重做和导出重载 |
| 改父级 | 改层级可能拆断两骨 IK 链，或引入 IK、Transform、Path 依赖环 | 提交前验证约束依赖，并在父级对话框显示具体拒绝原因 |

凹轮廓使用未修改的 JTS 1.20.0。来源、SHA-256、EDL/EPL 全文在 `lib/`，发布脚本随应用复制许可文件。

## 验证方法

- Java 回归覆盖皮肤优先级、动画附件、激活骨骼/约束、状态恢复、结构快照、约束层级、坐标转换和自动打键。
- 凹轮廓测试检查像素覆盖、简化边界误差与面积、UV、凹口、噪点、无效拓扑及一次撤销/重做。几何对照示例从 120 顶点减为 18 顶点仍保留 C 形凹口。
- HTML 使用公开 Spine 4.3 Web Player，在无头 Chromium 中检查桌面与窄屏下的纹理渲染、动画位移、暂停、组合后的附件颜色和错误提示。
- 桌面 UI 使用隔离偏好设置的隐藏 OpenGL 进程导出截图，检查 1920×1080 与 1280×720；进程自行退出，不操作用户现有窗口。
- 77 组 Java 回归通过。HTML 的三种可播放样例分别在 960×700、390×844 检查；桌面皮肤组合、世界坐标、凹轮廓对话框分别在两种尺寸截图验证。长皮肤名溢出经截图发现并修复后重新验证。
- 没有完成官方编辑器逐帧 golden 对照，不宣称数值完全一致。

交付程序：`publish-candidate/spine-pro-review-2/OpenSpine/OpenSpine.exe`，基础版本 `0.2.91`，源码/构建输入指纹 `9a6adef17a045ed81910634ade49f5cafe17233377c08f82c68c36374c1a9510`。同目录提供包含 Java 运行环境的 win64 ZIP。截图留在 `artifacts/round2-ui-check/`，HTML 验证留在 `artifacts/html-export-check/fixtures/`。

## 仍建议继续补齐

| 优先级 | 剩余差异 | 当前边界与后续方向 |
| --- | --- | --- |
| 高 | 原生 OpenSpine 工程保存 | `openspine-project.json` 是打包快照，普通保存只写骨架文件，不更新项目成员、顺序和名称。当前需重新打包；后续应保留工程关联，增加全工程原子保存及失败恢复 |
| 高 | Setup 骨骼/附件补偿 | 参考资源含骨骼、附件补偿入口。当前改父级会迁移引用并保护约束，但不能据此保证全动画或子附件的世界姿态不变；需要单独设计保持姿态及动画补偿模式 |
| 中 | 更完整的图片描边 | 当前凹轮廓限单一无孔区域；还缺孔洞、多岛、多轮廓编辑及更细的内部点分布控制 |
| 中 | 完整坐标操作 | 当前新增的是父级/世界平移；尚无骨骼自身局部轴增量移动，也未扩展为各坐标系下的旋转、缩放补偿 |
| 中 | 完整皮肤工作流 | 当前为有序预览组合，未实现将组合烘焙为永久新皮肤、跨项目皮肤迁移或完整固定皮肤管理 |
| 中 | 工程打包与资源迁移 | 仍需先解压再打开清单；绝对或越界图片/音频路径会拒绝打包，尚未实现收集并重定向为包内路径；仅有 atlas 时不能重建原 loose 图片目录 |
| 中 | HTML 离线播放器 | 骨架、图集、图片已内嵌，播放器 JS/CSS 仍从 CDN 加载；可进一步增加固定版本的完全离线导出 |
| 持续 | 官方兼容性证据 | `.spine` 通过已安装并激活的官方 CLI 从 runtime 数据重建；不能还原未导出的原生元数据。Physics/Slider 等仍需真实官方样例的逐帧 golden 对照 |

参考资源：`editor/languages/chinese-sc`（皮肤、补偿、坐标）、`editor/hotkeys-default.txt`（Generate）、`archive/2/languages/chinese-sc`（Concavity、Trace）、`editor/export/template-player.html`。公开 Player 的皮肤数组配置另外通过真实浏览器运行验证。

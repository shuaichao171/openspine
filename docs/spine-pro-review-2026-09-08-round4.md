| 离线 HTML | 数据和图片已内嵌，播放器 JS/CSS 仍从通配版本 CDN 加载，断网无法播放 | 固定官方 Spine Player 4.3.5，将未修改的脚本、样式及完整许可文本嵌入单个 HTML；断网可播放动画、组合皮肤及无动画 Setup 项目，无远程资源请求 |

| 保存取消 | 扩大资源校验后，若在提交锁内哈希大音频，会阻塞取消按钮 | 完整解析和流式哈希在提交前的可取消后台阶段完成；最终提交只检查刚采集的路径和文件元数据，并原子替换工程清单。另存时已有目标的基线校验也移入后台 |

## 使用方式

1. 在播放栏或附件面板点“组合…”，选择皮肤并调整顺序。点“应用”仍是预览；输入新名称后点“保存为新皮肤”，才会创建永久皮肤。之后正常保存工程或导出 JSON/SKEL。
2. 骨骼属性中的“移动坐标”选择“本地”。输入 ΔX 或 ΔY，例如 ΔX=10 表示沿主选骨骼自身 X 轴移动 10 个局部单位，包含该轴缩放；完成后输入框归零。
3. 按原入口“导出项目 → HTML 动画播放器”导出。新的 HTML 默认离线可用，无需复制其他播放器文件。
4. 若打开后外部修改了工程图片或音频，保存会报告冲突；重新打开以采用磁盘状态，或使用项目另存为保存到新位置。完整资源校验增加磁盘读取量，大资源工程的打开和保存时间会相应增加。

## 参考证据与实现边界

参考 JAR 的 `editor/languages/chinese-sc` 以英文原文为键，含 `Merge Skins`、`For each merged attachment, the keys in each animation are also duplicated`、`Source meshes are merged as linked meshes`、`Use local or parent axes to rotate more than 360 degrees.`、`Package Project`、`Missing image files (%1).`、`Missing audio files (%1).`、`Export HTML`、`Player` 和 `Web Components`。

这些资源证明相关功能入口或选项存在，不证明参考软件的保存事务性、HTML 离线性或具体数值算法。本轮永久组合采用独立网格快照，与参考资源所述保留 Linked Mesh 关联的方式不同；尚无“保持与源网格联动”的组合选项。

| 优先级 | 仍需补齐的部分 | 当前边界 |
| --- | --- | --- |
| 高 | 完整 Setup / 动画补偿 | 改父级仅支持上一轮限定条件下的 Setup 世界姿态补偿；尚无全动画关键帧重算、一般 Setup 移动时的骨骼与附件补偿 |
| 中 | 孔洞与多岛凹描边 | 仍限单一无孔凹轮廓，需要专门的连桥或附件拆分设计 |
| 中 | 其他坐标变换 | 本轮补的是局部轴移动；其他坐标系的旋转、缩放及相关补偿仍未完整对齐 |
| 中 | 皮肤结构编辑 | 皮肤改名等沿现有结构修改规则清理历史；永久组合的独立副本会增加附件和动画数据量，不保持与源网格联动。复杂工程中同名附件的跨皮肤轨道仍需更清晰的归属标注 |
| 中 | 资源维护 | 仍拒绝越界/绝对图片音频路径；任意内存图集仍需外部来源。旧资源版本保留且不自动清理；清单必须与 `.openspine-generations` 目录一起传输 |
| 持续 | 文件系统竞态与性能 | 内容哈希后以元数据再验普通文件变化；无法为任意不协作的外部写入提供绝对线性一致保证。大型工程尚无增量资源去重与快速校验缓存 |
| 持续 | 原生 Spine 工程与数值一致性 | `.spine` 仍是经已安装并激活的官方 CLI 重建 runtime 可表达数据；不是保真回写。Physics/Slider 等尚需真实官方编辑器逐帧 golden 对照 |

本轮不声称 OpenSpine 已与 Spine Pro 功能或数值行为完全一致。

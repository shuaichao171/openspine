# Spine Pro 对照审查：第五轮

日期：2026-09-08。延续[第四轮](spine-pro-review-2026-09-08-round4.md)，参考本机 `spine_jar/Spine Pro/Pro_4.3.23.jar` 的界面资源，并审查 OpenSpine 的编辑、历史和工程打开流程。本轮不运行参考编辑器，不使用其闭源实现。

## 本轮修改

| 功能 | 确认的问题 | 修改后的行为 |
| --- | --- | --- |
| 附件轨道归属 | 不同皮肤的同名 Deform/Sequence 轨道显示相同，持久选择键也缺少皮肤，可能恢复到错误目标 | 行标签按“类型 · 皮肤 · 占位”显示，避免长皮肤名遮住类型；检查器、搜索和悬停说明包含完整归属；持久选择键增加皮肤字段，旧键只在唯一匹配时恢复 |
| 共享及继承附件 | 附件可以跨皮肤共享，Linked Mesh 也可能继承源附件轨道，不能简单按当前预览皮肤命名 | 按实际轨道附件建立归属，说明共享注册与继承关系；改名或删除某项注册时保留仍存在附件的选择；查看轨道不改变预览皮肤 |
| 皮肤历史 | 新建、复制、改名和删除会通过结构刷新清空历史，无法继续撤销此前编辑 | 四项操作进入撤销历史；改名使用固定的前后 Skin 实例，撤销恢复原对象，保持此前永久组合、姿态和轨道编辑的引用有效 |
| 皮肤关联状态 | 只恢复皮肤列表不足以恢复删除及改名的影响 | 同步恢复预览组合、权重锁、相关 Setup 占位和跨槽附件轨道激活关系，迁移附件轨道选择；默认皮肤与已有引用保护规则继续生效 |
| 大工程打开 | 完整资源哈希在渲染线程重复执行，大图片/音频工程会卡住且无法取消校验阶段 | 在后台完成资源发现、完整内容检查及打开快照；渲染线程前后仅做文件元数据复验，并加载候选纹理；取消、过期回调及当前工程变化会阻止采用候选 |
| 加载失败清理 | 多页图集的后续页损坏时，构造期间已创建的前页纹理可能无法被候选文档释放 | 先建立可释放的图集，再加载页面；异常时释放已加载页面，保留原工程 |

## 使用方式

1. 在摄影表查看或搜索 Deform/Sequence 轨道时，可以直接输入皮肤名称。长名称的完整归属可在悬停说明中查看。
2. 在“附件皮肤”面板执行新建、复制、重命名或删除皮肤，使用原有撤销/重做入口回退。受动画或 Linked Mesh 引用保护的操作仍会说明原因并拒绝。
3. 打开 `.openspine-project.json` 或解压项目包的 `openspine-project.json` 时，会显示资源检查进度窗口；可以取消。后台完成后才创建候选纹理，成功后采用整个项目。

## 参考证据与边界

本机参考 JAR 的 `editor/languages/chinese-sc` 包含 `Merge Skins`、`Renames each duplicate attachment using the skin name`、`Pinned skins will be shown under each skin placeholder`、`Delete skin placeholders`、`Sequence`、`Package Project`、`Missing image files (%1).` 和 `Missing audio files (%1).`。

这些资源支持对照皮肤、附件名称及工程资源管理能力，不能证明参考编辑器采用与本轮相同的轨道标识、撤销实现或异步加载机制。本轮修改依据 OpenSpine 中已确认的缺口与失败场景，使用官方公开运行时 API 验证。

| 仍需补齐的部分 | 当前边界 |
| --- | --- |
| 完整 Setup / 动画补偿 | 改父级仅支持限定条件下的 Setup 世界姿态补偿；没有全动画关键帧重算和一般 Setup 骨骼/附件补偿 |
| 复杂网格轮廓 | 单一无孔凹轮廓已支持，孔洞、多岛及点接触仍需专门设计 |
| 其他坐标变换 | 已有父级、世界、本地轴移动；其他坐标系的旋转、缩放和补偿尚未完整对齐 |
| 皮肤组合选项 | 永久组合使用独立快照，尚无保持源网格关联的组合选项；普通复制的非 Mesh 动画引用限制仍保留 |
| 更广泛的结构撤销 | 本轮补齐皮肤四项操作，不代表所有附件和约束结构修改都可以保留历史 |
| 附件面板布局 | 长内容仍可能超过面板宽度，需要横向滚动；本轮未重排整个附件检查器 |
| 大工程加载性能 | 图片解码、纹理上传和运行时加载仍在渲染线程，最后阶段仍可能短暂停顿；文件元数据复验不是对任意不协作写入的绝对一致保证 |
| 资源维护 | 仍拒绝绝对/越界资源路径；历史资源版本尚无自动清理、增量去重和快速校验缓存 |
| 原生 Spine 与数值一致性 | `.spine` 仍经已安装并激活的官方 CLI 重建 runtime 可表达数据，不是无损回写；Physics/Slider 仍需真实官方编辑器逐帧对照 |

本轮不声称 OpenSpine 已与 Spine Pro 功能或数值行为完全一致。

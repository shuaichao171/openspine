日期：2026-09-08。延续[第六轮](spine-pro-review-2026-09-08-round6.md)，本轮集中审查视区显示、导航和临时求值开关，并修复确认的功能差距。

用户给出的 `spine/_jar/Spine Pro` 路径在当前工作区不存在；实际参考文件为 `spine_jar/Spine Pro/Pro_4.3.23.jar`，大小 49,768,720 字节，SHA-256 为：

`00f922595d3b9eb62e14b71a3d2f00fc6c492b7de57b20fe7dfe1207a8abd8b5`

本轮只读取 JAR 中公开的 `editor/languages/chinese-sc` 界面资源，不运行参考编辑器，也不反编译或借用其闭源实现。该资源明确包含以下文案：

| --- | --- |
| `Flip viewport` | 视区翻转 |
| `Lock viewport zoom` | 锁定视区缩放 |
| `Pixel snapping is on.` | 像素吸附状态 |
| `When translating, region attachments snap to screen pixels` | 移动 Region 附件时对齐屏幕像素 |
| `Disable all constraints` | 临时禁用全部约束 |
| `Pixel grid limits skeleton rendering to 2048x2048.` | 另有带专门渲染限制的像素网格功能 |

这些文案只能证明参考编辑器公开了相应能力，不能证明其内部算法或数据结构。本轮实现依据 OpenSpine 的现有架构和官方 Spine 4.3 runtime API 独立完成。

## 本轮修复

| 功能 | 原问题 | 修改后的行为 |
| --- | --- | --- |
| 翻转视区 | 只能以默认水平方向观察，缺少 Spine Pro 对应入口 | “界面”菜单与设置页可水平翻转视区；渲染、拾取、骨骼及 Mesh 拖拽、平移和光标锚点缩放统一使用翻转坐标；骨骼名称保持正常文字方向；切换时取消未完成拖拽，避免坐标突变 |
| 锁定缩放 | 滚轮始终改变视区缩放 | 锁定后仍消费视区滚轮事件，但不改变缩放，防止事件穿透；“显示全部”和“聚焦选中”仍可主动调整取景 |
| Region 像素吸附 | 移动附件时不能对齐屏幕像素 | 只在移动当前选中的 Region 附件时，以附件原点对齐实际 GL 帧缓冲像素；支持高 DPI、翻转视区和 X/Y 轴约束，不会在受限轴的垂直方向产生位移 |
| 禁用全部约束 | 缺少查看未约束动画和 Setup 姿态的总开关 | 当前骨架可临时从 runtime update cache 旁路 IK、Transform、Path、Physics 和 Slider；主姿态、动画、残影、撤销恢复和 Slider 预览遵守开关；求值后按原对象及原顺序恢复 cache，不修改作者数据或混合值 |
| 入口与快捷键 | 相关操作缺少一致入口 | 顶栏新增“界面”菜单，设置的“视口”页同步提供开关；默认快捷键为 `Shift+F`、`Shift+L`、`Shift+I`、`Shift+C` |
| 旧偏好迁移 | 新动作的默认组合可能已被旧版用户自定义绑定占用 | 加载旧偏好时保留已有用户绑定，并为冲突的新动作选择空闲组合，不覆盖或交换旧绑定 |

翻转、缩放锁定和像素吸附属于工作区偏好，退出后恢复。禁用约束属于每个已打开骨架的临时检查状态，切换骨架标签时保留，但不写入 Spine 数据、Sidecar 或原生工程。

## 使用方式

1. 从顶栏“界面”菜单或“设置 → 视口”切换视区翻转、缩放锁定、像素吸附及禁用全部约束。
2. 开启像素吸附后，选择 Region 附件并使用移动工具拖动；骨骼、Mesh、旋转、缩放和倾斜不使用此吸附。
3. 禁用全部约束适合检查未受约束的骨骼姿态。重新启用后立即按当前播放时间恢复约束求值，不会生成历史项或修改工程。

## 当前边界

| 仍需补齐的部分 | 当前边界 |
| --- | --- |
| 像素网格 | 本轮没有实现。参考文案表明它包含像素一致性提示和 2048×2048 渲染限制，不能用现有普通线框网格冒充 |
| 像素吸附范围 | 严格按公开文案只处理 Region 平移；Mesh 顶点、骨骼和其他变换不吸附 |
| 缩放锁定范围 | 阻止用户滚轮缩放；显式“显示全部”和“聚焦选中”仍会改变相机，这是为了保证导航命令可用 |
| 禁用约束持久化 | 这是临时诊断状态，不导出也不随重启恢复；若未来需要工程级状态，应单独定义兼容格式 |
| PSD 同步 | 第六轮只建立了可靠来源模型，仍未实现按映射更新图层、区域和用户后续编辑的同步流程 |
| 通用补偿与坐标系 | 全动画关键帧补偿、一般 Setup 骨骼/附件补偿，以及旋转和缩放的更多坐标系仍未完整对齐 |
| 复杂网格轮廓 | 孔洞、多岛和点接触轮廓仍需要专门的拓扑与交互设计 |
| 官方数值一致性 | Physics/Slider 仍需要真实官方编辑器产生的逐帧 golden trace 扩大场景对照 |

本轮不声称 OpenSpine 已与 Spine Pro 功能或数值行为完全一致。

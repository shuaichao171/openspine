## 本轮修复

| 问题与触发 | 修改后的行为 |
| --- | --- |
| 多通道 Bezier 中，X 两端相同但中间回弹；只编辑 Y 手柄会压平 X | 未编辑通道直接保留原 runtime 采样，不经过端点差归一化重建 |
| 复制整段回弹曲线、单曲线粘贴，或在轨道末尾追加普通键，会丢失既有回弹 | 相同端点差按数值偏移与时间映射保留采样；支持快照撤销/重做 |
| 两端数值相同的回弹曲线在 Graph 被画成直线，手柄无法向上/下编辑 | 内嵌/独立 Graph、曲线轨道和多轨概览使用真实数值手柄绘制、取景和拖动；相邻手柄联动按真实斜率计算，Deform 的帧序号偏移单独转换 |
| 父级单轴零缩放时，直接编辑子骨骼父级坐标也被逆矩阵流程拒绝 | 主选和同父级多选直接应用作者坐标差；不同父级仍按共同世界位移转换，整组预检后提交 |
| 有效的极小缩放被固定阈值当成零，极大缩放的 float 行列式溢出 | 使用 double 中间计算；实际奇异矩阵及不可表示的结果仍拒绝，有限可逆尺度正常移动 |
| Mesh/Deform/权重拖动中翻转视区，手势仍使用旧起始坐标；切换全部约束有同类问题 | 先取消手势并恢复原几何、权重和 Deform，再改变坐标或求值状态；后续旧拖动/释放事件不会产生修改 |
| Esc 只能取消骨骼，Deform/Weight 还可能没有键盘焦点 | 视区所有已处理的鼠标按下统一取得键盘焦点；Esc 同时支持 Mesh、Deform、权重和视区平移 |
| Deform 取消时不能把受约束结果写回未约束数据 | 分别保存并恢复原 Pose 和 AppliedPose 的数组，保留空数组与两者差异 |
| Region 沿旋转父级/本地轴移动时，屏幕 X/Y 吸附使位移偏离实际轴线 | 对实际轴的主要屏幕分量吸附，并沿原轴修正；兼容翻转和不同 DPI 比例 |

斜线不一定经过屏幕像素交点，因此轴向吸附只保证主要屏幕分量落在像素上，同时保持轴线约束。自由移动继续对齐两个屏幕分量。

同端点回弹可使用 Graph 和“存储曲线”完整编辑与复制；现有比例曲线预设无法表达它，新增预设时会说明原因并指向“存储曲线”。旧比例编辑弹窗遇到同端点段会打开数值 Graph。主动应用平坦预设仍会按用户要求改变曲线；原样提交数值手柄不会新增修改。

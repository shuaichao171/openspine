## 已完成的修改

| 项目 | 审查发现 | 本轮结果 |
| --- | --- | --- |
| 全工程保存 | 原“保存项目”实际只写当前 Runtime；从项目包打开后，成员增删和顺序不能随普通保存恢复 | 菜单“保存项目 / 项目另存为”保存完整 OpenSpine 工程；打开后 Ctrl+S 更新全部骨架、资源、顺序、活动骨架和编辑状态 |
| 工程成员管理 | 模型已有移动能力，但缺少管理入口和工程成员的未保存判定 | 增加“管理骨架”，支持重命名、排序及重名检查；添加、删除、改名、排序都进入工程未保存状态，排序同时迁移对应撤销历史 |
| 保存失败恢复 | 分别覆盖多个骨架会出现一部分保存成功、一部分失败的工程 | 先写入独立资源版本，最后原子替换清单；取消、异常、并发保存、保存期间编辑或外部数据修改时保留旧工程；不删除原 `.spine` 和旧资源版本 |
| 内置示例可保存性 | 内置示例只有内存图集，原打包器拒绝保存图片 | 两个示例复用原 Pixmap 绘图生成 PNG/atlas 来源；完整工程保存及重开后，图集参数和渲染像素一致 |
| 副本与原工程状态 | Runtime 另存和 Spine 重建会影响原工程的关联与保存点；直接 Runtime 导出可覆盖工程清单 | 原生工程中的副本导出保留工程关联和未保存标记；数据写入入口拒绝将 Runtime 写到工程清单或受管资源版本中 |
| 放弃修改后重开 | 自动根侧车可能把未保存的 bounds/FPS/路径/mix 等参数恢复出来，却显示为已保存 | 根侧车改为明确的视图字段白名单；读取旧完整侧车也只恢复视图；完整创作状态随显式工程保存进入资源版本 |
| 成员修改的自动恢复 | 第一次保存工程之前发生的成员变化，在崩溃恢复后会丢失“需要保存整个工程”的信息 | 自动快照为所有成员保留工程恢复标志，恢复后按整个工程另存，避免改写旧 Runtime 或已提交资源版本 |
| Setup 改父级 | Pro 资源有补偿选项；普通改父级仅保留本地值，世界姿态可能跳变 | 增加“保持 Setup 世界姿态”，用隔离骨架求解局部变换，再验证骨骼矩阵和附件顶点；支持一次撤销/重做与保存点恢复 |
| 大坐标精度 | 网格仿射残差按绝对坐标放宽：百万坐标下 20 px 的变形也被接受，描边会抹去形变 | 改用局部尺度与浮点精度，覆盖平移、旋转、细分和非有限值；Setup 补偿也使用浮点精度限制，拒绝超过容差的漂移 |
| SKEL 资源预检 | 多骨架打包缺少单骨架路径已有的 `.skel` + loose 图片检查 | 在保存前拒绝该不支持组合，避免成功保存后不能带图重开 |

## 使用方式

1. 使用“项目 → 保存项目”选择 `名称.openspine-project.json`。已解压的 `openspine-project.json` 也可以直接打开并继续保存。
2. 使用“项目 → 管理骨架”修改名称或顺序。打开原生工程后，Ctrl+S 保存整个工程；工具栏“另存为”导出当前 Runtime 副本。
3. 在骨骼属性中修改父级，可选择“保持 Setup 世界姿态”。当前有未应用的相关姿态时，先重置或“设为 Setup”；不支持的约束或动画依赖会显示具体原因。
4. 工程清单和同目录 `.openspine-generations` 资源目录共同构成工程。传输时使用“打包项目”更方便；不能只复制清单文件。崩溃恢复后的工程会要求另选保存位置。

## 验证结果

- 全量 81 组 Java 回归测试通过。新增全工程事务、成员保存状态、内置示例资源与 Setup 改父级测试。
- 全工程保存实际验证：首次保存，修改未激活骨架，管理弹窗改名/排序，删除/添加成员，再次保存，释放后重开；同时核对全部撤销历史保存点。
- 失败场景覆盖取消、异常、文件冲突、并发内存修改、Runtime 副本保留未保存标记，以及放弃参数修改后重开。
- 自动恢复验证覆盖尚未第一次保存工程时的成员变化，以及恢复后仍按整个工程保存。
- Setup 测试覆盖五种继承模式、镜像、非均匀缩放/剪切、零长度、百万坐标，以及加权/关联网格顶点保持。正常与拒绝弹窗均执行真实应用、撤销、重做和未保存状态检查。
- 管理骨架及 Setup 父级弹窗在 1280×720、1920×1080 下导出截图并逐张检查；隐藏验证进程使用隔离偏好及自动保存目录，结束后全部退出。
- 内置图集的内存版本与保存重开的磁盘版本，在两种缩放下逐字节渲染一致。网格描边、细分、自动权重各阶段实际输出 JSON/SKEL 并经官方开源读取器重读。

| 中 | 资源归集与磁盘维护 | 仍拒绝越界/绝对图片或音频路径；任意外部内存图集还需提供原始图片。旧资源版本会累积，暂不自动清理；冲突指纹覆盖工程清单、Runtime 和相关状态，不覆盖图片/音频内容 |

| 持续 | 原生 Spine 工程与数值一致性 | `.spine` 仍通过已安装并激活的官方 CLI 重建 runtime 可表达数据，不是保真回写；Physics/Slider 等仍需来自真实官方编辑器的逐帧 golden 对照 |
